# SparkFinance

A Shark Tank-style investment simulation web app for high school students. Players pick a shark investor, hear startup pitches, make and counter offers with a live valuation calculator, track their fund, and build a portfolio scorecard. Built for the 2026 Congressional App Challenge.

**Submission deadline: Monday, October 26, 2026, 12:00 PM ET.**

## The one rule that matters

**Every line of code in this folder is written by Naina.**

## How to run it

No build tools, no frameworks, nothing to install. Open `index.html` in any browser and play.
