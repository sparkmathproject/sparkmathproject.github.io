# SparkFinance Build Plan

36 days to the deadline (Oct 26, 2026, noon ET). One checkbox at a time.

## Week 1: Setup (Sept 19 - 25)

- [ ] Register at congressionalappchallenge.us (no entry fee)
- [ ] Play the reference MVP once and write down the screens in order: start, shark select, pitch, offer, results
- [ ] Learn HTML basics: headings, paragraphs, buttons, divs, inputs
- [ ] Create the page structure in `index.html`: one section per screen, only the start screen visible

## Week 2: Make it look good (Sept 26 - Oct 2)

- [ ] Learn CSS basics: colors, fonts, spacing, centering
- [ ] Style every screen: start, shark select, pitch, offer, results
- [ ] Add the four sharks with names and personalities (your own original characters)
- [ ] Add the four startup pitches with asking price and equity offered

## Week 3: JavaScript part 1 (Oct 3 - 9)

- [ ] Learn JS basics: variables, functions, click handlers
- [ ] Screen navigation: buttons move the player from screen to screen
- [ ] Shark selection: clicking a shark saves the choice and shows it on later screens
- [ ] Pitch screen: shows the startup's story, asking price, and equity

## Week 4: JavaScript part 2 (Oct 10 - 16)

- [ ] Offer logic: player types an offer, shark accepts / counters / walks away
- [ ] Valuation calculator: offer amount and equity update the valuation live
- [ ] Fund tracking: start with a fixed fund (example: $1,000,000), subtract each investment
- [ ] Portfolio scorecard: list of deals made, money left, simple win/loss count

## Week 5: Playtest and polish (Oct 17 - 23)

- [ ] Have 2-3 friends or family play it and write down everything confusing
- [ ] Fix the bugs they found
- [ ] Write the demo video script: what the app is, how it works, what you learned (keep it short)
- [ ] Record the demo video and upload it to YouTube or Vimeo (unlisted is fine)

## Submit (Oct 24 - 25)

- [ ] Final playthrough on a fresh browser: every button works, no dead ends
- [ ] Submit code + video at congressionalappchallenge.us before noon ET on Oct 26
- [ ] Submit a day early if you can. Do not trust deadline-day internet.

## Rules to remember

- The code must be yours, written by you, created after October 30, 2025.
- One app per student per year, one district (NJ-07).
- Any programming language and any topic are allowed. Plain HTML/CSS/JS is a great choice.
